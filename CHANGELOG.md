# Changelog

## 2.0.0

- Add Safari Web Extension support (macOS) via Xcode project
- Add Firefox support (v109+) with `browser_specific_settings.gecko`
- Cross-browser API polyfill (`globalThis.browser || globalThis.chrome`)
- One codebase now supports Chrome, Safari, and Firefox

## 1.3.1

- Context-aware shortcut reference modal (? key)
- Inbox-aware shift hints overlay

## 1.3.0

- Inbox list view with navigation (j/k), selection (x), and actions
- Sidebar mailbox cycling (v/V)
- Toolbar actions: status, priority, assign, tag from inbox

## 1.2.3

- Initial release with ticket detail keyboard shortcuts
- Status (o/p/c/d), priority (`/1/2/3), assign (a), tag (t), reply (r)
- Shift+status to set and advance
- Navigation between tickets (j/k)
